# Rock vs Mine Prediction using Machine Learning

This project is a Machine Learning-based classification system that predicts whether an underwater object is a Rock or a Mine using SONAR signal data.

The model is trained using the SONAR dataset, which contains 60 numerical attributes representing the energy of sonar signals bounced back from different surfaces. The system uses Logistic Regression for binary classification and provides accurate predictions based on the input data.

## Features
- Data preprocessing and analysis
- Train-test data splitting
- Logistic Regression model training
- Prediction system for custom input data
- Model accuracy evaluation

## Technologies Used
- Python
- NumPy
- Pandas
- Scikit-learn
- Jupyter Notebook / Google Colab

## Machine Learning Algorithm
- Logistic Regression

## Dataset Information
The dataset contains:
- 60 input features
- 1 output label
  - `R` = Rock
  - `M` = Mine

## Project Workflow
1. Import Dataset
2. Data Preprocessing
3. Splitting Training and Testing Data
4. Training the Model
5. Evaluating Accuracy
6. Building Predictive System

## Purpose of the Project
The main goal of this project is to understand the implementation of Machine Learning algorithms for binary classification problems using real-world SONAR data.

## Output
The system predicts whether the detected object is:
- Rock
- Mine
